# Airis

[English](README.md) | **Русский**

Локальный голосовой ИИ-компаньон. Работает полностью офлайн: LLM через Ollama, долговременная память в ChromaDB, потоковый синтез речи (Silero TTS) и распознавание речи (faster-whisper).

## Возможности

- **Чат с LLM** через [Ollama](https://ollama.com) (по умолчанию `T-lite-it-1.0` Q4_K_M) с потоковым выводом в терминал.
- **Потоковый TTS** — речь озвучивается по предложениям, пока модель ещё генерирует ответ. Используется Silero, голос `baya`, ресемплинг до 48 кГц.
- **Голосовой ввод (STT)** — faster-whisper (`large-v3-turbo` `int8` на CPU по умолчанию), режим push-to-talk (клавиша `space`) с post-roll буферизацией (250 мс) для предотвращения обрезки окончаний слов, фильтрация шума/вдохов через VAD и conversational barge-in.
- **Долговременная память** — факты о пользователе и о самой Airis автоматически извлекаются из диалога и хранятся в ChromaDB. Эмбеддинги — `bge-m3` (1024-d), с поддержкой русского языка. Поиск по косинусной близости, дедупликация фактов.
- **Инициатива в паузах (idle)** — после паузы в разговоре Айрис может сама сказать короткую спонтанную реплику. Пока идёт озвучка или запись голоса, реплика откладывается; подряд их не больше `idle.max_idle_messages`.
- **Live2D-аватар** — подключение к [VTube Studio](https://denchisoft.com/) по WebSocket: синхронизация губ по аудио TTS в реальном времени (по RMS) и горячие клавиши эмоций по тегу эмоции в ответе. Если VTube Studio не запущен, аватар пропускается, остальное работает как обычно.
- **Сессии** — история диалога (последние 12 ходов) сохраняется атомарно на диск и восстанавливается при запуске.
- **Корректное завершение** — по `Ctrl+C`, `SIGTERM` или команде выхода сбрасывается очередь озвучки, сохраняются сессия и память.

## Требования

- Windows (проект разрабатывался и тестировался под Windows)
- Python 3.10+
- [Ollama](https://ollama.com) с загруженными моделями:
  ```bash
  ollama pull hf.co/aovchinnikov/T-lite-it-1.0-Q4_K_M-GGUF
  ollama pull bge-m3
  ```
- Модель Silero TTS (`model.pt`), путь к ней задаётся в `config.yaml`
- Модель Faster-Whisper `large-v3-turbo` (~1.6 ГБ). Скачивается автоматически при первом запуске или предварительно:
  ```bash
  python -c "from faster_whisper import WhisperModel; WhisperModel('large-v3-turbo', device='cpu', compute_type='int8')"
  ```
- Микрофон и устройство вывода звука

## Настройка

Все параметры находятся в [`config.yaml`](config.yaml):

| Секция | Что настраивает |
|--------|-----------------|
| `ollama` | адрес сервера, модель, модель эмбеддингов, параметры генерации |
| `tts` | путь к `model.pt`, голос, высота тона, частота дискретизации, mute |
| `stt` | модель Whisper (`large-v3-turbo`), compute_type (`int8`), потоки CPU (6), beam_size (1), initial_prompt, VAD-фильтрация, пороги галлюцинаций, post-roll для PTT (250 мс), горячая клавиша |
| `memory` | каталог ChromaDB, порог дистанции, дедупликация, размер истории |
| `idle` | инициатива в паузах: вкл/выкл, мин/макс пауза, лимит реплик подряд |
| `avatar` | хост/порт VTube Studio, путь к токену, сглаживание lip-sync, соответствие эмоция → горячая клавиша |
| `logging` | каталог и файлы логов |
| `personality` | имя пользователя по умолчанию, лимит эмодзи |

**Обязательно** поправьте `tts.model_path` — в конфиге указан локальный путь автора (`C:\LLM\Instruments\model.pt`).

## Системный промт (нужно указать вручную)

Системный промт / персонаж **не входит** в репозиторий. Перед первым запуском создайте его вручную:

1. Скопируйте пример: `copy system_prompt.example.txt system_prompt.txt`
2. Отредактируйте `system_prompt.txt` и опишите нужный характер и стиль.

Примечания:
- Файл читается в UTF-8 и игнорируется git. Без него `run.py` завершится с ошибкой.
- Можно использовать плейсхолдер `{user_name}` (заменяется на имя пользователя). Фигурные скобки как обычный текст экранируйте: `{{` и `}}`.
- Промт **обязан** требовать, чтобы каждый ответ начинался с одного тега эмоции: `[neutral]`, `[happy]`, `[smug]`, `[surprised]`, `[angry]`, `[blush]`, `[bored]` или `[thinking]`. На них опираются потоковый фильтр и аватар.
- Необязательно: `idle_prompt.txt` настраивает инструкции для спонтанных реплик в паузах. Поддерживает `{user_name}` и `{forbidden_phrases}`. Если файла нет, используется нейтральный встроенный текст.

## Запуск

Убедитесь, что Ollama запущена, затем:

```bash
python run.py
```

Для выхода используйте команду выхода в чате или `Ctrl+C`.

## Команды чата

| Команда | Действие |
|---------|----------|
| `/help` | список команд |
| `/mute` | включить/выключить озвучку |
| `/memories` | показать сохранённые факты |
| `/forget` | удалить факт из памяти |
| `/name <имя>` | запомнить имя пользователя |

## Структура проекта

```
airis/
├── config.py        # загрузка и валидация config.yaml
├── avatar/          # клиент VTube Studio, lip-sync, контроллер аватара
├── core/            # команды, жизненный цикл, инициатива в паузах, блокировки, промпты, потоковый вывод
├── memory/          # ChromaDB, извлечение фактов, история сессии, логи памяти
├── stt/             # запись, VAD, push-to-talk, barge-in, Whisper
└── tts/             # разбиение на предложения, нормализация текста, синтез, ресемплинг
run.py               # точка входа
system_prompt.example.txt  # пример системного промта (скопируйте в system_prompt.txt)
config.yaml          # конфигурация
PROJECT.md           # подробное описание архитектуры и этапов
```

## Данные, которые не попадают в репозиторий

Эти файлы создаются при работе и перечислены в `.gitignore`:

- `Model/` — веса моделей (`*.gguf`, `*.pt`, `*.onnx`)
- `chroma_db/` — векторная база памяти
- `Logs/` — логи, история сессии, дамп памяти
- `*.session` — сессии Telegram (приватные данные)
- `system_prompt.txt`, `idle_prompt.txt` — ваши личные промты

## История изменений (Changelog)

- **v0.5 (2026-10-31)** — Модель STT по умолчанию обновлена с `small` на **`large-v3-turbo`** (`int8` на CPU, 6 потоков, поддержка `initial_prompt`), добавлены Silero VAD и фильтрация вдохов/кашля/40+ русских галлюцинаций Whisper, добавлена post-roll буферизация PTT (250 мс) против обрезки окончаний слов, ограничены потоки CPU для Silero TTS (`torch.set_num_threads(4)`), добавлено разрешение конфликтов фактов в памяти (`insert`/`replace`/`delete`) и авто-саммари сессии при выходе. Подробнее в [CHANGELOG.md](CHANGELOG.md).
- **v0.4 (2026-10-11)** — Интеграция Live2D-аватара через VTube Studio (lip-sync по RMS и эмоции по хоткеям), инициатива в паузах (idle) и вынос личного `system_prompt.txt` из исходников.
